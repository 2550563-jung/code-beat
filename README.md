# code-beat

브라우저에서 바로 연주되는 리듬게임이에요. 음악은 Web Audio로 실시간 합성되고, 설치 없이 `index.html` 하나로 동작해요.

**플레이:** https://2550563-jung.github.io/code-beat/

**PC · 안드로이드 앱:** [Releases](https://github.com/2550563-jung/code-beat/releases/latest)에서 `code-beat-setup.exe`(Windows) 또는 `code-beat.apk`(안드로이드)를 받으세요. 게임 메뉴의 "앱 받기"에서도 받을 수 있어요.

**아이폰 · 아이패드:** Safari로 사이트를 열고 공유 → 홈 화면에 추가를 누르면 앱처럼 전체 화면으로 실행돼요. 앱은 게임을 웹에서 불러오기 때문에 게임 업데이트가 바로 반영되고, PC 앱은 앱 자체도 자동으로 업데이트돼요.

## 기능

- 200단계 맵 (1·2·4키, 마지막 전설 단계는 6키), 난이도 3단계, 보통 이상으로 깨면 다음 레벨이 열리는 진행
- 멀티플레이: 방 코드로 최대 8명이 같은 맵을 동시에, 실시간 점수
- 맵 레벨 · 난이도 · 노트 속도에 따라 점수 배율이 붙는 통합 점수
- 체력과 과부하(빈 입력 연타) 실패 규칙
- 메트로놈을 따라 누르는 자동 입력 보정
- 레인 수별 키 설정, 레인마다 다른 드럼 히트사운드
- 닉네임 + 비밀번호 로그인으로 기기 간 기록 동기화 (닉네임은 중복 불가)
- 온라인 랭킹: 누적 점수, 맵·난이도별, 커뮤니티 레벨별
- 커뮤니티 레벨: 최신 · 인기 · 많이 한 순, 검색, 좋아요
- 레벨 에디터: 그리드에 노트 배치, mp3 음악(파형 표시·탭 BPM), 코드 진행 · 조 · 음색 선택, 미리듣기, 테스트 플레이, 업로드, .cbeat 파일 저장·불러오기, 되돌리기·다시 하기, 구간 복사·붙여넣기·좌우 반전, 곡 중간 BPM 변화, 예상 난이도
- 오늘의 도전: 매일 바뀌는 맵과 별도 랭킹, 첫 클리어 보너스
- 연습 모드(구간 반복, 0.5~1.5배 속도)와 모드(미러 · 랜덤 · 히든)
- 리플레이: 최고 기록의 입력을 저장해 랭킹에서 다시 보기
- 업적 22개와 칭호, 출석 보상, 월간 시즌 랭킹(상위 10명 한정 아이템)
- 친구 · 프로필 · 커뮤니티 레벨 신고 · 멀티플레이 반응
- 상점: 노트 · 테마 · 타격 효과 · 히트사운드 · 판정선 · 배경 · 판정 글자
- 색약 모드, 1분 튜토리얼

## 조작

| 키 수 | 기본 키 |
|---|---|
| 1 | Space |
| 2 | F J |
| 4 | D F J K |
| 6 | S D F J K L |

모바일은 레인을 터치하면 돼요. Esc는 일시정지예요.

## 서버

랭킹 · 계정 · 커뮤니티 레벨은 Supabase에 저장돼요. 브라우저는 공개(publishable) 키로 `bb_` 함수만 호출하고, 테이블에는 직접 접근할 수 없어요. 비밀번호는 bcrypt 해시로만 저장돼요.

음악 파일(mp3)은 Supabase Storage `cb-audio` 버킷에 저장되고, 업로드는 로그인 세션을 확인하는 엣지 함수 `cb-upload-audio`를 거쳐요.

## 앱 빌드

`v1.0.1` 같은 태그를 푸시하면 GitHub Actions가 Windows 설치 파일과 APK를 만들어 Release에 올려요.

안드로이드 앱 업데이트를 덮어쓰기로 설치하려면 서명 키가 항상 같아야 해요. 저장소 Settings → Secrets and variables → Actions에 다음 두 값을 넣어 주세요. 없으면 빌드마다 새 키로 서명돼서, 업데이트할 때 기존 앱을 지우고 설치해야 해요.

- `ANDROID_KEYSTORE_BASE64`: 키스토어 파일을 base64로 바꾼 값
- `ANDROID_KEYSTORE_PASSWORD`: 키스토어 비밀번호 (별칭은 `codebeat`)

키스토어 만들기: `keytool -genkeypair -keystore release.keystore -alias codebeat -keyalg RSA -keysize 2048 -validity 10000`
